# Sahithi Reddy portfolio (hero)

Next.js 14 + React Three Fiber + GSAP ScrollTrigger.

```bash
npm install
npm run dev
# open http://localhost:3000
```

Where things live
- `lib/data.js` skills, projects, stage copy and links (edit content here)
- `lib/shaders.js` chrome and iridescent blob shaders (palette lives here)
- `components/BlobScene.jsx` the 3D scene: blob, skill nodes, project satellites
- `components/Hero.jsx` pinned scroll story, nav pill, text stages
- `app/globals.css` theme colors and layout
